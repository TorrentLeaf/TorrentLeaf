# /test — Escrever ou melhorar testes

Use para criar testes para código existente.

## Prompt
Escreva testes para: $ARGUMENTS

Siga o guia do agente `.claude/agents/testing.md`.
Garanta cobertura mínima definida no agente de testing.
Use mocks (mockery para Go, vi.mock para TS) para isolar dependências externas.
