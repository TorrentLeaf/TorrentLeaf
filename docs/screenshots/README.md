# Screenshots

Drop your captures here using the **exact filenames** below — the root `README.md`
references them directly. PNG recommended, captured at a 1440×900 (desktop)
viewport for the wide shots.

| Filename | What to capture | Notes |
| --- | --- | --- |
| `landing.png` | Public landing page (`/`) | Hero shot — used at the top of the README. Full-width looks best. |
| `library.png` | Library / dashboard (`/library`) | Logged in, with a few torrents and the transfer chart visible. |
| `reader-manga.png` | Manga/comic reader | A page open in webtoon or paginated mode. |
| `reader-document.png` | PDF or EPUB reader | Whichever looks cleaner. |
| `video-player.png` | Video player (`/watch`) | With controls / track selector visible. |
| `add.png` | Add torrent page (`/add`) | The magnet input form. |
| `settings.png` | Settings page (`/settings`) | Reader defaults / download path. |

## Tips

- Keep file sizes reasonable (compress PNGs; aim for < ~500 KB each).
- For crisp text, capture at 1× (avoid 2× retina unless you also halve the display size).
- The grid in the README pairs images two-per-row, so similar aspect ratios look tidier.
